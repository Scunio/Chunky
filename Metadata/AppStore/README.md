# App Store localizations

`localizations.json` contains the app-level and version-level metadata for Italian, US English, Spanish (Spain), German, French, Dutch, and Portuguese (Portugal).

App Store Connect drafts were created for iOS 1.0.7 and macOS 1.0.8. Their seven text localizations are in `PREPARE_FOR_SUBMISSION`; they are not live on the App Store until a build and the required media are submitted and approved.

The existing Italian screenshots have been copied to every locale for now. They still show Italian interface text; replace them with localized captures later if desired.
